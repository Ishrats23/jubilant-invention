# jubilant-invention

##Overview
This is a simple calculator application built using C# and WPF, developed as part of a coursework project. It provides basic arithmetic operations through a user-friendly interface.

##Features
Basic Operations: Addition, Subtraction, Multiplication, Division
Clear Function: Resets the calculation
Error Handling: Handles invalid inputs like division by zero

##How to Run
###Clone the repository:

git clone https://github.com/Ishrats23/jubilant-invention.git
Open the solution (A2IshratVohra.sln) in Visual Studio.
Build and run the application.

##Technologies Used
C#, .NET Framework, WPF
